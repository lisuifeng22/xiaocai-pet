# 小菜时间感知功能设计

## 概述
让小菜（桌面宠物 AI）在对话中感知当前日期和时间，能准确回答"今天几号""星期几"等问题，同时保持傲娇性格的随机感。

## 改动范围
只改动 `backend/app.py` 中的 `build_system_prompt()` 函数，一行注入。

## 实现方式
在 system prompt 末尾追加一行当前时间字符串：
```
当前时间：2026年5月21日（星期四） 15:30
```

由 DeepSeek 模型自行理解并融入回复，不需要额外的逻辑判断或关键词匹配。

## 时间格式
- 中文日期格式，包含年、月、日、星期、时分
- 使用 Python `datetime` 模块获取

## 为什么不需要特殊处理
- DeepSeek 是通用大模型，能理解日期概念并推理
- 傲娇性格设定 + 0.9 temperature 保证回复自然多样，不会千篇一律报时间
- 每次对话都注入，小菜一直有"时间感"，日常对话也更自然

## 变更清单
| 文件 | 改动 |
|------|------|
| `backend/app.py` | `build_system_prompt()` 末尾添加 1 行日期注入 |
